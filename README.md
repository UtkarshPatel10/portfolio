# Utkarsh Patel — Portfolio

Personal portfolio of Utkarsh Patel, ISTQB® certified Senior QA Automation Engineer.

**Live:** https://utkarshpatel10.github.io/portfolio/

Built with HTML, CSS, JavaScript and Bootstrap 5. No build step.

## Run locally
Open `index.html` in a browser, or:
```
python3 -m http.server 8000
```

## Structure
```
index.html        page markup
css/style.css     styles
js/main.js        nav, animations
assets/           certificate PDF
```
